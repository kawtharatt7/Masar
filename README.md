# Masar (مسار)

Career path and skill-gap analysis for university students. Next.js App Router, Supabase Auth + Postgres, Gemini through the Vercel AI SDK. Arabic (RTL) and English (LTR).

## Setup

1. `npm install`
2. Copy `.env.example` to `.env.local` and fill in:
   - `GEMINI_API_KEY` from https://aistudio.google.com/apikey
   - `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY` from Supabase > Project Settings > API
3. In Supabase > SQL Editor, run `supabase/schema.sql` (tables, row-level security, new-user trigger, score history). It is safe to run again after updating the project.
4. Supabase > Authentication:
   - Providers > Email: enabled. Turn "Confirm email" off for instant sign-in while developing, or leave it on and users confirm by link.
   - Providers > Google: enable it and paste your Google OAuth client ID and secret. In Google Cloud, add the callback URL shown by Supabase as an authorized redirect URI.
   - URL Configuration: set Site URL to `http://localhost:3000` and add your production URL to Redirect URLs.
5. `npm run dev`, then open http://localhost:3000

## Model name

`gemini-1.5-flash` has been retired from the Gemini API, so calls to it return a 404. The server uses `GEMINI_MODEL` from `.env.local` and falls back to `gemini-2.5-flash`. Set `GEMINI_MODEL` to any model your key can access.

## How it works

- `src/lib/server.ts`: Gemini model factory, JSON fence cleaning, Supabase token check, error mapping. Real errors from Gemini or Supabase are returned to the browser as `{ error }`.
- `src/app/api/roles/route.ts`: role suggestions from major, year and interests.
- `src/app/api/analyze/route.ts`: accepts a PDF (sent to Gemini natively) or pasted text, validates the JSON with zod, saves it to `progress`.
- `src/components/`: `Welcome` (auth), `Profile` (setup and role discovery), `Assess` (CV input, results, roadmap tracking).
- Roadmap check-offs are written to `progress.completed_steps`.

## Deploy on Vercel

1. Push the project to GitHub and import the repository in Vercel (framework: Next.js, no extra settings).
2. Add the environment variables in Project Settings > Environment Variables: `GEMINI_API_KEY`, `GEMINI_MODEL` (optional), `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, and optionally `NEXT_PUBLIC_INTRO_VIDEO_URL`.
3. Deploy, then in Supabase > Authentication > URL Configuration set Site URL to your Vercel domain and add `https://YOUR-DOMAIN/**` to Redirect URLs. Google sign-in fails until this is done.
4. The analysis route allows up to 60 seconds (`maxDuration` in `src/app/api/analyze/route.ts`). If your Vercel plan caps functions lower, requests will time out; shorten `maxTokens` there.

## Notes

- The market outlook text is generated by Gemini from general industry knowledge. It is not live job-posting data.
- Tailwind CSS and Framer Motion are used by the landing page, role chips, tag inputs, roadmap accordion and progress chart. The earlier screens still use the classes in `src/app/globals.css`, which sits in the Tailwind `components` layer so utilities can override it.
- Wireframe guidance for Figma is in `docs/wireframes.md`.

## Updates (packs 1 to 5)

- Speed: Gemini 3.x thinks by default. `GEMINI_THINKING_BUDGET` (default 0 = off) controls it; the analysis runs as two parallel calls.
- Onboarding: step-by-step profile, large major list, AI suggestions for courses and skills, guided role questionnaire.
- Projects: each roadmap step is completed by documenting its project; achievements are stored in the `achievements` table (`supabase/pack-3-achievements.sql`), with a congratulation screen and LinkedIn sharing.
- Motion: roadmap, scroll reveals, page transitions, score count-up.
- Adding components from 21st.dev: see `docs/adding-21st-components.md`.
